# Echoes of What We Never Said 📜✨

> *"A collection of things that were felt, but perhaps never said."*

An immersive, cinematic 20-poem digital book showcasing the complete original poetry collection by **Rishusingh**. Built with Vite, React, Framer Motion, HTML5 Canvas, and Web Audio API.

---

## 🌟 Features

- **📖 20 Original Poems by Rishusingh**: Complete collection structured into a continuous 8-stage emotional narrative arc (*Beginning*, *Admiration*, *Intimacy*, *Conflict*, *Distance*, *Agony & Loss*, *Realization*, *Acceptance*).
- **✨ Poetic Titles**: Every poem features a unique title crafted around its emotional atmosphere and imagery.
- **🎨 Cinematic Aesthetic**: Editorial serif typography (`Cormorant Garamond` & `Playfair Display`), ambient dust particles, animated film grain, and dark vignette overlays.
- **🧊 Interactive 3D Depth**: Mouse cursor parallax tilt and perspective layers.
- **🗺️ "The Journey" Timeline Map**: An interactive emotional timeline allowing readers to preview and jump to any poem.
- **Sparkles "The Story Between Them"**: An unlocked master narrative canvas connecting the hidden story across all 20 poems.
- **🎵 Web Audio Ambient Atmosphere**: User-toggled generative synthesizer soundscape.
- **⬆️ Instant Scroll-to-Top**: Every poem transition automatically resets scroll position to the title and first line.

## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (v18+) installed.

### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/echoes-poetry.git

# Navigate to the project directory
cd echoes-poetry

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be available at `http://localhost:5173/`.

### Production Build

```bash
# Build for production
npm run build

# Preview production build
npm run preview
```
