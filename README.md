# Echoes of What We Never Said

> *"A collection of feelings once felt, but perhaps left unspoken."*

**Echoes of What We Never Said** is an immersive digital poetry experience showcasing a collection of 20 original poems. The web application is built with React, Vite, Framer Motion, HTML5 Canvas, and the Web Audio API to provide a cinematic, interactive reading environment.

## Key Features

- **20 Original Poems**: A complete collection structured into an 8-stage emotional narrative arc (*Beginning*, *Admiration*, *Intimacy*, *Conflict*, *Distance*, *Agony & Loss*, *Realization*, *Acceptance*).
- **Cinematic Aesthetic**: Editorial typography (`Cormorant Garamond` & `Playfair Display`), ambient canvas particles, animated film grain, and dark vignette overlays.
- **Interactive Depth & Parallax**: Mouse cursor parallax tilt and perspective layering for an engaging reading experience.
- **Emotional Timeline Map**: An interactive navigation menu allowing readers to explore the emotional arc and jump to specific poems.
- **Master Narrative View**: A hidden canvas ("The Story Between Them") connecting the underlying narrative across all 20 poems.
- **Generative Ambient Audio**: User-controlled ambient soundscapes powered by the Web Audio API.
- **Responsive Design**: Designed for optimal reading across desktop and mobile devices.

---

## Tech Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Canvas & Sound**: HTML5 Canvas & Web Audio API

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18+) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/amritanshu-kishor/echoes-of-what-we-never-said.git
   ```

2. Navigate to the project directory:
   ```bash
   cd echoes-of-what-we-never-said
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

The application will be available at `http://localhost:5173/`.

### Production Build

To compile static assets for production:

```bash
npm run build
```

To preview the built bundle locally:

```bash
npm run preview
```
